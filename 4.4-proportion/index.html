母比率の推定・検定

母比率の点推定・信頼区間・z検定の考え方と計算を学びます。

ヒント：このモジュールで学ぶこと

「推定」・「仮説検定」モジュールでは「連続型の量的データ（身長・血圧・点数など）の平均」を推定・検定してきました。今回はデータの種類が変わります。

「この薬の治癒率は本当に50%より高いか？」「内閣支持率は前回から変わったか？」——結果が「治癒した・しない」「賛成・反対」のような2値データでは、「平均」ではなく**母比率 p**（母集団における成功の割合）が関心の母数です。基本的な考え方（標本から信頼区間を作り、仮説検定を行う）は母平均の場合と同じですが、使う分布と計算式が変わります。

1. 母比率の点推定と区間推定

n 個の独立な試行で成功が X 回だったとします。標本比率 p^​=X/n は母比率 p の不偏推定量です。

X∼B(n,p)（二項分布）なので E[p^​]=p、V[p^​]=p(1−p)/n です。中心極限定理より n が大きいとき：

p^​≈N(p,np(1−p)​)

標準誤差 SE=p(1−p)/n​ ですが p は未知なので p^​ で代入します。母比率の近似 1−α 信頼区間は：

p^​±zα/2​np^​(1−p^​)​​

例：n=200、X=80（治癒40%）の95%信頼区間。

p^​=20080​=0.40,SE=2000.40×0.60​​≈0.0346

CI=0.40±1.96×0.0346≈(0.332,0.468)

SE∝1/n​ なので、信頼区間の幅を半分にするには n を4倍にする必要があります（4n​ で SE が半分になるため）。

2. 母比率の仮説検定（z検定）

「治癒率が50%より高い（p>0.5）か」を検定したいとき、帰無仮説 H0​:p=p0​ を立てます。

H0​ が正しいとすると p^​ は近似的に N(p0​,p0​(1−p0​)/n) に従うので、検定統計量は：

z=p0​(1−p0​)/n​p^​−p0​​∼N(0,1)

信頼区間と検定で SE の計算が変わる理由： 信頼区間は「p が何かわからないから推定する」ので、p の代わりに手元の p^​ を使います。検定は「H0​:p=p0​ が正しいと仮定した世界での分布」を作るので、仮定した値 p0​ を使います。同じ標本データを使っていても、目的が違うから SE の計算式が変わります。

例：n=200, p^​=0.55, H0​:p0​=0.50 の片側検定。

z=0.5×0.5/200​0.55−0.50​=0.03540.05​≈1.41

有意水準5%の片側棄却域 z>1.645 に入らないので H0​ を棄却できない。

試験ポイント：試験ポイント： 母比率の検定では SE に p0​（帰無仮説の値）を使い、信頼区間では p^​（標本比率）を使う。この使い分けを問う問題が頻出です。

よくある誤解・つまずき

  • **標準誤差 SE の使い分けに注意。** 信頼区間は手元の p^​、検定は仮定値 p0​ を使います（目的が違うため）。
  • 比率の推定・検定は正規近似（中心極限定理）が前提です。 n が小さい、または p が0や1に極端に近いと近似が崩れます。
  • **区間の幅を半分にするには n を4倍にする必要があります**（SE∝1/n​）。
  • **標本比率 p^​ は割合（0〜1）です。** 個数 X と取り違えないこと（p^​=X/n）。

ここまでのまとめ

  • 標本比率 p^​=X/n は母比率 p の不偏推定量。
  • 大標本では p^​≈N(p,np(1−p)​)（正規近似）。
  • 信頼区間：p^​±zα/2​np^​(1−p^​)​​。
  • 検定統計量：z=p0​(1−p0​)/n​p^​−p0​​。SE は区間＝p^​、検定＝p0​。

確認クイズ（抜粋）

Q1. 標本比率 p̂ = X/n の期待値として正しいのはどれか（p: 母比率）。

A. p

Q2. 母比率の検定で H₀: p = p₀ を検定する場合の検定統計量の SE として正しいのはどれか。

A. √(p₀(1−p₀)/n)（帰無仮説の値を使う）

Q3. n = 100, p̂ = 0.6 の95%信頼区間の半幅はほぼいくつか（z = 1.96）。

A. 0.096
