中心極限定理と二項分布の正規近似

中心極限定理・標準誤差・二項分布の正規近似を理解し、統計的推測（Chapter 4）の土台を作ります。

ヒント：このモジュールで学ぶこと

Chapter 4 では「標本から母集団を推測する」方法を学びます。でも、なぜそんなことが可能なのでしょうか？

その根拠となる定理が中心極限定理（CLT）です。「母集団がどんな形の分布でも、サンプルサイズが大きければ標本平均の分布は正規分布で近似できる」という驚くべき事実です。正規分布で近似できるから確率計算ができる——だから推定や仮説検定が成り立ちます。

1. まず直感から——「平均を取ると安定する」

1つのサイコロを1回振ると、出る目は1〜6のどれか。バラツキが大きいです。

では、10人それぞれがサイコロを1回ずつ振って10人の平均を求めたらどうなるでしょう？ 1人だけが「6」を出しても、他の9人の目が平均的なら、10人の平均は大きく外れません。さらに100人の平均を取れば、もっと安定します。

人数が増えるほど、極端な値が打ち消し合い、平均はブレにくくなる——これが中心極限定理の直感です。

2. 中心極限定理（CLT）の中身

この「平均を取ると安定する」という直感を数学的に正確に述べたのが中心極限定理（CLT: Central Limit Theorem）です。驚くべきことは「母集団がどんな形の分布でも（一様分布でも、右裾が長い歪んだ分布でも）この定理が成り立つ」という点です。

母集団の平均を μ、分散を σ2 とします。このとき n 個のデータをランダムに取って計算した標本平均 Xˉ は、n が十分大きければ次の正規分布に従います：

Xˉ∼N(μ,nσ2​)

この式が言っていること：

  • 標本平均の中心は母平均 μ と同じ（平均的に見れば正しい値を指している）
  • 標本平均のばらつき（分散）は σ2/n（n が大きいほど小さくなる）
  • 母集団の形が何であれ、正規分布で近似できる

試験ポイント：試験ポイント： 「母集団がどんな分布でも」という点が重要です。母集団が歪んだ分布でも、n が大きければ標本平均は正規分布になります。

3. 標準誤差（SE）——標本平均のブレを数値で表す

標本平均の分散が σ2/n なので、その標準偏差（＝ブレの大きさ）は：

SE=n​σ​

この値を特別に標準誤差（SE: Standard Error）と呼びます。

サンプルサイズを変えると SE はどう変わるか：

  • サンプルサイズ **n**：標準誤差 σ/n​
  • サンプルサイズ **4n（4倍）**：σ/(2n​)（元の半分になる）
  • サンプルサイズ **9n（9倍）**：σ/(3n​)（元の3分の1になる）

ヒント：「精度を2倍にしたければ、サンプルサイズを4倍にする必要がある」——現実のアンケート設計でも重要な知識です。

4. 二項分布の正規近似（試験頻出）

コインを100回投げるとき、表が出る回数 X は B(100,0.5) に従います。「ちょうど60回表が出る確率」を二項分布の式で厳密に計算しようとすると、C(100,60)×(0.5)60×(0.5)40 ——100! を含む計算です。手計算はおろか電卓でも大変です。

「近似」のアイデア： n を大きくすると、二項分布のヒストグラムはだんだん左右対称の滑らかな鐘型に近づいてきます。この形は正規分布にそっくりです。ならば「二項分布の代わりに正規分布で計算してしまおう」——これが正規近似の発想です。

なぜ正規分布に近づくのか？ CLTがその理由を与えます。B(n,p) は「成功＝1・失敗＝0 という試行の n 回の合計」と見なせます。合計（平均 × n）は多くの独立試行の足し算——つまりCLTの条件を満たすので、n が大きくなると正規分布に近づきます。

近似の公式： 二項分布の期待値（np）と分散（np(1−p)）を使って正規分布を当てます。

B(n,p)≈N(np,np(1−p))(n が十分大きいとき)

  • 正規分布の期待値（第1引数）：np
  • 正規分布の分散（第2引数）：np(1−p)
  • 正規分布の標準偏差：np(1−p)​

注意：第2引数は分散です。標準偏差 np(1−p)​ ではありません。ここは頻出のひっかけです。

近似が使える目安： np≥5 かつ n(1−p)≥5

この条件は「成功側にも失敗側にも、最低5回以上の期待値がある」ことを意味します。例えば n=100,p=0.02 なら期待成功数は 100×0.02=2 回（5未満）——ほとんどが失敗で分布が左（0のほう）に極端に偏り、対称な正規分布の形になりません。一方 n=100,p=0.5 なら成功も失敗も期待50回で、きれいな山型の正規分布に近くなります。

ステップごとに解いてみよう： コインを100回投げたとき表が出る回数 X∼B(100,0.5)

Step 1： 期待値と分散を計算する

  • 期待値：np=100×0.5=50
  • 分散：np(1−p)=100×0.5×0.5=25
  • 標準偏差：25​=5

Step 2： 正規近似で書く

X≈N(50,25)

Step 3： 「表が60回以上出る確率」を求める

Z=560−50​=2.0

正規分布表より P(Z≥2.0)≈0.023（約2.3%）

試験ポイント：試験ポイント： 計算手順は「①期待値 np・分散 np(1−p) を求める → ②N(np,np(1−p)) と書く → ③標準化して確率を読む」の3ステップです。

ヒント：Chapter 4 への橋渡し： 次の章では、Xˉ∼N(μ,σ2/n) という事実を使って、母平均の信頼区間と仮説検定を行います。CLT があるからこそ、母集団の形に関わらず正規分布の計算で推測できるのです。

よくある誤解・つまずき

  • **CLT の n は「1つの標本に含まれるデータ数（標本サイズ）」です。** 「標本を何回取ったか（標本の数）」ではありません。
  • 母集団は正規分布でなくてかまいません。 どんな形の母集団でも、n が大きければ標本平均が正規分布に近づくのがCLTの驚くべき点です（個々のデータが正規になるわけではない）。
  • **標準誤差 SE=σ/n​ は「標本平均のばらつき」です。** 母集団そのものの標準偏差 σ とは別物。
  • **二項分布の正規近似 N(np,np(1−p)) の第2引数は分散です**（標準偏差ではない）。頻出のひっかけ。

ここまでのまとめ

  • 中心極限定理：母集団の形によらず、n が大きければ Xˉ∼N(μ,nσ2​)。
  • 標準誤差 SE=σ/n​。精度を2倍にするには n を4倍に。
  • 二項分布の正規近似 B(n,p)≈N(np,np(1−p))（目安 np≥5 かつ n(1−p)≥5）。
  • 確率は標準化して正規分布表で読む。

発展：3級では母分散 σ2 が既知の前提で標本平均の分布を扱います。実際には σ が分からないことのほうが多く、そこで標本標準偏差を代わりに使うと t 分布が現れます。t 分布・χ2 分布・F 分布までを含めた標本分布の全体像は、統計検定2級の「標本分布と中心極限定理」 で扱っています。

確認クイズ（抜粋）

Q1. 中心極限定理（CLT）の説明として正しいのはどれか。

A. 母集団の分布の形に関わらず、n が十分大きければ標本平均の分布は正規分布に近づく

Q2. 中心極限定理の説明として正しいのはどれか。

A. 母集団の分布の形を問わず、n が十分大きければ標本平均の分布は正規分布に近づく

Q3. 標準誤差（SE）の式 SE=σ/n​ から読み取れることとして正しいのはどれか。

A. サンプルサイズを4倍にすると、標本平均の標準偏差は2分の1になる
